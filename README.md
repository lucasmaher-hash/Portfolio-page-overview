# Portfolio Page Overview

[Open the GitHub Pages demo](https://lucasmaher-hash.github.io/Portfolio-page-overview/).

Five linked static pages: Agentic Workflow Overview, Struktur & Text, UI-Elemente, Wireframes and Bildgenerierung. This is a design-course prototype, not a production agent pipeline or a published portfolio case study. The public demo omits private Hermes chat links, local live status and local-only PNG export.

`src/` contains the source snapshot. The build scripts depend on additional assets and references on the author's machine, so this repository alone does not rebuild the demo. The four built HTML pages can be opened directly.
